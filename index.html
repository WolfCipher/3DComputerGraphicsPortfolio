Portfolio 2: 3D Graphics

This portfolio is a bit different from Portfolio 1. It asks you to make some 3D things but they are pretty much taken directly from the workbook draft assignments that you’ve already done. In almost all cases, we’re asking you for something you’ve already done (sometimes with minor changes). This portfolio is a chance for you to make things better (or just use the things you have).

Each page has a specific thing for you to do. You can, of course, add more but make sure that we can see the requirements.

We have made this portfolio use a similar directory structure to the workbooks which should facilitate moving your code from the workbooks to here. (the files in for_students have exactly the same names as the corresponding workbook files).

On each page (below the graphics box) there is a space for you to describe what you’ve done (if it isn’t obvious from looking at the graphics).

You aren’t restricted by the “ground rules” from the earlier workbooks. Now that you’ve learned about textures and meshes, you are free to use them. So, you can use textures, materials, object models, etc. for all of the assignments here. Or, you can also do things the way you did it in the workbook. For example, the Snowman was in Workbook 6, so you couldn’t use textures for it - now you can (if you want to).

We haven’t covered shaders in class (yet). For this assignment, we expect you to use THREE’s build in materials. If you want to write your own shader, we won’t complain.

While you are allowed to add mesh objects that you find, there are some rules for this:

  1. You must provide attribution (on the web page say where the mesh came from - if you made it, say so; if you got it from someplace, explain and give a link).
  2. You may only use meshes that the class has license to use (they should be “open source”) - preferably with a creative commons license. If you are in doubt, ask.
  3. Finding an object should not replace the spirit of the assignment. Don’t make a snowman by finding one and loading it.

  3. Amusement Park Rides

Completeness is most important. Make sure that you have everything working (mainly by copying over things from your workbooks). And then make it nicer. Having decent versions of everything is better than having great versions of a few things (and missing some others).
